# GoTorch Review Checklist

- [ ] Aligns with fundamental architecture and roadmap phase.
- [ ] Correctness and numerical behavior are tested.
- [ ] Shape/size arithmetic is overflow-safe.
- [ ] Ownership, aliasing, and lifetime are explicit.
- [ ] Concurrency is bounded and race-tested.
- [ ] Cancellation and shutdown are safe.
- [ ] Distributed failure behavior is defined where relevant.
- [ ] No mandatory vendor/GPU/CGo dependency was introduced into core.
- [ ] Windows AMD64 and Linux compatibility considered.
- [ ] Documentation and examples updated.
- [ ] Benchmarks are reproducible and claims are evidence-based.
