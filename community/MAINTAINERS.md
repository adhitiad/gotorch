# Maintainers

## Current status
The repository owner is the current project lead. No additional maintainer team is declared by this document.

## Responsibilities
- Triage issues and identify duplicates.
- Review correctness, tests, API compatibility, and security implications.
- Keep roadmap status evidence-based.
- Maintain documentation, CI, and release quality.
- Communicate decisions and review feedback respectfully.

## Becoming a maintainer
There is no automatic promotion threshold. The project lead may invite contributors after sustained high-quality work, dependable reviews, good judgment, and constructive community participation.

## Access
Use least-privilege GitHub permissions. Enable multi-factor authentication. Never share credentials or use personal tokens in CI. Review access periodically and remove it when no longer needed.
