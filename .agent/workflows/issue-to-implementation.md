# Workflow: Issue to Implementation

1. Classify the issue under P0–P13.
2. Confirm scope and acceptance criteria.
3. Identify affected package contracts and dependencies.
4. Create an implementation plan.
5. Implement the smallest end-to-end slice.
6. Test correctness, boundary conditions, and concurrency.
7. Update docs/ADR if needed.
8. Run CI-equivalent checks.
9. Summarize evidence and unresolved risks.
