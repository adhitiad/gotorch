# Support

## Where to ask
- Usage questions and design discussion: GitHub Discussions.
- Reproducible defects: GitHub issue form for bug reports.
- Feature proposals: feature request issue form.
- Security vulnerabilities: private GitHub Security Advisory reporting.

## Before asking
1. Search existing issues and discussions.
2. Include Go version, GoTorch commit or release, OS, architecture, and exact commands.
3. Provide a minimal reproducible example.
4. Redact credentials, tokens, personal information, and proprietary data.

## Expectations
This is a community project, not a guaranteed commercial support service. Response times depend on maintainer and contributor availability. Please be patient and keep follow-up information in the original thread.
