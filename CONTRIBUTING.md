# Contributing to GoTorch

1. Read `AGENTS.md` and relevant `.agent/rules/`.
2. Identify the roadmap phase and acceptance criteria.
3. Open an issue or document the implementation plan for non-trivial changes.
4. Keep changes focused; add tests and docs.
5. Run `gofmt`, `go test ./...`, `go vet ./...`, and relevant race/benchmark checks.
6. Report platform coverage honestly.
7. Do not claim performance improvements without reproducible benchmark evidence.

By contributing, you agree to follow the project's code of conduct and license terms once formally adopted. License selection is currently pending.
