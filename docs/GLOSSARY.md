# Glossary

- **Autograd:** automatic computation of derivatives through an operation graph.
- **Collective:** coordinated communication operation among distributed ranks.
- **DDP:** distributed data parallel training.
- **IR:** intermediate representation used by compiler passes.
- **Kernel:** implementation of a mathematical tensor operation.
- **NUMA:** non-uniform memory access topology.
- **Placement:** mapping of tensors or computation to a process/device/rank.
- **Reference kernel:** simple correctness-oriented implementation used as a baseline.
- **SIMD:** single instruction, multiple data vector execution.
- **Storage:** backing memory owned or referenced by a tensor.
- **View:** tensor metadata referencing existing storage, often with different shape/strides.
