# Agent Workspace

This directory contains repository-specific operating rules, reusable skills, workflows, and task templates for coding agents.

- `rules/`: mandatory engineering constraints by domain.
- `skills/`: task playbooks agents should follow.
- `workflows/`: repeatable multi-step procedures.
- `templates/`: issue, implementation-plan, and review templates.

Root `AGENTS.md` remains authoritative. These files refine it; they do not override it.
